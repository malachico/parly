# Reporting a security issue

Report vulnerabilities privately to the repository owner, Malachi Cohen, using
an existing private contact or a private security review thread in Parly.
Confirm that the thread is not publicly shared before including details.
If you cannot reach the owner privately, ask for a private reporting channel
without describing the vulnerability.

Include the affected commit or version, the required access, reproduction
steps, expected and actual behavior, and the potential impact. Use test data;
do not include credentials, tokens, personal data, or other tenants' content.
Do not test against production users or infrastructure without authorization.

Keep exploit details out of public connector issues and shared Parly threads.
Security fixes require an independent review before deployment. This project
does not promise a response time or offer a bug bounty through this document.
